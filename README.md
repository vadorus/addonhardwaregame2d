# Tycoon Hardware

Projet de jeu de gestion 2D sous Godot, centré sur la conception et la commercialisation de matériel informatique.

## Vision

Le joueur développe une entreprise hardware et fait évoluer ses gammes de composants : CPU, GPU, RAM et cartes mères. La boucle de jeu visée combine R&D, conception produit, production, coûts, ventes, réputation et parts de marché.

## État du dépôt

Ce dépôt sert désormais de dépôt GitHub pour **Tycoon Hardware**.

Le projet Godot actuellement présent sur le PC de développement n'a pas encore été importé ici. Il faudra synchroniser le dossier réel depuis le PC avant de poursuivre le développement afin d'éviter de reconstruire ou d'écraser des fichiers existants.

## Prochaine étape

Importer le projet Godot réel depuis le PC de développement, puis établir un état des lieux du code et reprendre la boucle jouable à partir de la version existante.
