# Plan maître des assets visuels — Tech Empire / Tycoon Hardware

## Principe général

Le jeu ne doit pas créer des dizaines de "niveaux visuels" artificiels.
L'évolution principale de l'entreprise repose sur un nombre limité de paliers crédibles.
Après ces paliers, la variété vient surtout de la personnalisation, des thèmes, des événements et des choix esthétiques.

Le joueur dirige. L'équipe conseille. Le jeu propose.

---

## 1. Paliers visuels de l'entreprise

### Palier 1 — Garage de départ
- espace réduit ;
- mobilier récupéré ;
- éclairage chaleureux ;
- peu d'équipement ;
- interface volontairement simple ;
- CPU comme première branche active.

### Palier 2 — Atelier technique
- meilleur établi ;
- rangement et instrumentation ;
- petite équipe ;
- premiers prototypes exposés ;
- premières personnalisations de décor.

### Palier 3 — Petit laboratoire / bureau technique
- espace R&D dédié ;
- plusieurs postes ;
- salle de réunion simple ;
- affichage de projets ;
- identité de marque plus visible.

### Palier 4 — PME technologique
- bureaux structurés ;
- équipes spécialisées ;
- laboratoire plus professionnel ;
- services RH / marketing / production visibles ;
- showroom ou espace produit possible.

### Palier 5 — Siège technique
- direction ;
- laboratoires spécialisés ;
- espaces de présentation ;
- meilleure image de marque ;
- plusieurs divisions possibles.

### Palier 6 — Campus R&D
- grands laboratoires ;
- centres de tests ;
- production / partenaires ;
- bâtiments dédiés ;
- prestige international.

### Palier 7 — Groupe technologique international
- plusieurs sites ;
- grandes divisions ;
- datacenters / centres spécialisés ;
- image de marque mondiale ;
- architecture plus ambitieuse.

### Palier 8 — Empire technologique
- campus mondiaux ;
- centres R&D de pointe ;
- branches hardware multiples ;
- identité visuelle fortement personnalisable ;
- prestige maximal.

Les paliers 7 et 8 peuvent rester tardifs et ne sont pas nécessaires à la première vertical slice.

## 2. Ce qui appartient à la progression gratuite

Chaque palier doit proposer un minimum de personnalisation gratuite.

Exemples :
- couleurs de marque ;
- affiches ;
- mobilier ;
- trophées ;
- plantes ;
- présentoirs ;
- objets techniques ;
- styles de laboratoire ;
- quelques arrière-plans ;
- quelques skins produit ;
- plusieurs apparences CPU.

La progression ne doit jamais donner l'impression que le jeu est vide sans achat.

---

## 3. Ce qui relève de la personnalisation

La personnalisation ne crée pas de nouveau palier.
Elle modifie l'apparence d'un palier existant.

Axes :
- thème chaleureux ;
- industriel ;
- rétro-tech ;
- minimaliste ;
- premium ;
- futuriste ;
- corporate ;
- expérimental ;
- saisonnier.

La même logique s'applique aux :
- QG ;
- laboratoires ;
- bureaux ;
- production ;
- marketing ;
- showroom ;
- équipe ;
- produits.

## 4. Cosmétiques premium possibles

Uniquement cosmétiques, sans avantage de gameplay décisif.

Exemples :
- fonds premium ;
- thèmes de laboratoire ;
- variantes de mobilier ;
- packs saisonniers ;
- effets d'ambiance ;
- styles d'interface ;
- styles typographiques ;
- skins CPU ;
- styles de packaging ;
- cadres / badges ;
- variantes de portraits ou vêtements.

Ordre de prix envisagé :
- mini pack : 0,99 €
- pack standard : 1,99 €
- pack thématique : 2,99 €
- gros pack premium : jusqu'à 4,99 €

Les prix sont indicatifs et seront validés plus tard.

---

## 5. Règle de cohérence des achats

Un cosmétique ne doit pas casser la progression.

Exemple :
- un skin "Campus R&D" n'est utilisable qu'après avoir atteint le palier correspondant ;
- un style de laboratoire avancé peut être acheté avant, mais seulement appliqué lorsque le lieu est débloqué ;
- un pack Halloween peut se superposer au lieu actuel, pas remplacer sa progression.

## 8. CPU — système visuel

Le joueur ne dessine pas le CPU de zéro.

Le système propose :
- plusieurs formes de package ;
- couleurs ;
- marquages ;
- finitions ;
- styles de série ;
- catégories de prestige ;
- styles adaptés au marché.

Modes :
1. automatique : l'équipe choisit ;
2. semi-guidé : l'équipe propose 2 à 4 options ;
3. avancé : le joueur ajuste les éléments déverrouillés.

Le mode semi-guidé est le mode principal recommandé.

## 9. Employés — variété et personnalisation

Ne pas produire un portrait unique par employé à la main.

Approche :
- bibliothèque de portraits cohérents ;
- plusieurs rôles ;
- variations de coiffure / tenue / accessoires / expression ;
- profils visuels distincts ;
- génération ou assemblage contrôlé pour limiter les doublons.

Données associées :
- spécialisation ;
- expérience ;
- compétence ;
- motivation ;
- loyauté ;
- fatigue ;
- salaire ;
- traits ;
- affectation ;
- potentiel.

## 13. Règle de production

Avant de créer un nouvel asset :
1. vérifier s'il existe déjà ;
2. identifier sa fonction ;
3. choisir son dossier ;
4. générer / produire ;
5. classer immédiatement ;
6. noter son statut : concept, validé, à intégrer, intégré ;
7. éviter les variantes inutiles.

Le but est d'avoir une bibliothèque cohérente, réutilisable et maintenable.


---

## 14. Règle officielle — intérieur en jeu, extérieur pour la progression

### En jeu
Le joueur doit principalement se sentir **à l'intérieur de son entreprise**.

Les fonds de gameplay doivent donc montrer en priorité :
- bureau du fondateur / direction ;
- laboratoire ;
- open space ;
- espace RH ;
- production ;
- showroom ;
- salle de réunion ;
- centre R&D ;
- datacenter ou atelier spécialisé selon la branche.

À chaque palier, l'intérieur évolue avec la taille et les moyens de l'entreprise.

### Façades / bâtiments extérieurs
Les vues extérieures servent surtout à :
- l'écran d'accueil ;
- le menu principal ;
- l'écran d'évolution de l'entreprise ;
- les changements de palier ;
- les transitions / chargements ;
- les cartes de progression ;
- éventuellement une vue "campus" ou "monde".

Elles ne doivent pas remplacer les fonds intérieurs des écrans de gestion.

### Conséquence pour les saisons
Halloween, Noël et les futurs thèmes saisonniers doivent être produits d'abord comme **variantes des intérieurs de gameplay**.
Les façades saisonnières restent secondaires et pourront être utilisées pour le menu ou les transitions.

### Règle de cohérence
Même lieu, même architecture de base, même angle de lecture autant que possible :
- version normale ;
- version Halloween ;
- version Noël ;
- futures variantes.

Le décor change, mais le joueur doit reconnaître immédiatement son entreprise et son palier.
