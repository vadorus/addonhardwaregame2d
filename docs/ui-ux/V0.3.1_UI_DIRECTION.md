# V0.3.1 — Direction UI/UX

## Objectif
Ne pas ajouter de grosse mécanique avant d'avoir rendu les premières minutes claires, chaleureuses et guidées.

## Principes
1. Une action principale dominante à la fois.
2. Nora Bernard est le bras droit du joueur et explique quoi faire, pourquoi et ce qui vient ensuite.
3. L'entreprise doit sembler vivante et évoluer visuellement : garage → atelier → bureau technique → siège → campus R&D.
4. L'interface doit avoir une vraie sensation de jeu de gestion, pas de tableau de bord administratif.
5. Les chiffres restent accessibles, mais les conséquences doivent être traduites visuellement.
6. Windows et Android utilisent le même gameplay et les mêmes données.

## Onboarding
Création entreprise → contexte 1971 → présentation de Nora → premier objectif → laboratoire CPU guidé → lancement du projet → déblocage Équipe → nouveau conseil Nora.

## Laboratoire CPU
Parcours en quatre étapes :
- Identité & marché
- Stratégie
- Conception technique
- Validation

## Équipe
Chaque employé doit pouvoir se distinguer par :
- spécialisation ;
- niveau / expérience ;
- compétence ;
- motivation ;
- loyauté ;
- fatigue ;
- salaire ;
- traits ;
- affectation ;
- formation / spécialisation future.

## Vision hardware
Le CPU est le point de départ, pas la limite du jeu.
Préserver la possibilité d'étendre les mêmes principes à GPU, RAM, cartes mères, stockage, IA, robotique et serveurs/datacenters.

## Branding
L'icône du jeu doit devenir un élément versionné et stable de l'identité visuelle.
Direction actuelle : microprocesseur carré, contour doré/ambre, cœur cyan, lisible en petite taille.

## Mobile
- paysage ;
- gros contrôles tactiles ;
- cartes empilables ;
- détails secondaires repliables ;
- aucun texte critique caché ;
- bouton principal toujours facile à atteindre.

## Critère de réussite
Un nouveau joueur doit savoir quoi faire sans connaître le projet et sans demander d'explication externe.
