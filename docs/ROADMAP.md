# Roadmap — Tycoon Hardware

Cette roadmap sert de cap. Elle sera ajustée après import et audit du vrai projet Godot depuis le PC de développement.

## Phase 0 — Récupération et stabilisation

- [ ] Importer le projet Godot réel depuis le PC.
- [ ] Vérifier la version Godot et les plugins utilisés.
- [ ] Vérifier que le projet démarre sur PC.
- [ ] Vérifier l'état Android/export mobile existant.
- [ ] Cartographier les scènes, scripts, autoloads et données.
- [ ] Identifier les fichiers générés ou locaux à exclure de Git.
- [ ] Établir une première version de référence reproductible.

## Phase 1 — Vertical slice CPU

Objectif : fabriquer et commercialiser un premier processeur de bout en bout.

- [ ] Écran de conception CPU.
- [ ] Paramètres de base : architecture/génération, cœurs, fréquence, IPC, cache, TDP, gravure.
- [ ] Coût et durée de R&D.
- [ ] Validation d'un design.
- [ ] Passage en production.
- [ ] Coût unitaire et volume produit.
- [ ] Prix de vente.
- [ ] Demande du marché.
- [ ] Ventes mensuelles.
- [ ] Marge et trésorerie.
- [ ] Réputation et première part de marché.

Critère de fin : une partie permet de concevoir, produire et vendre au moins un CPU avec conséquences économiques mesurables.

## Hors scope immédiat

Ne pas développer ces éléments avant d'avoir une vertical slice CPU stable :

- multijoueur ;
- backend en ligne ;
- boutique ;
- monétisation ;
- IA concurrentielle complexe ;
- contenu massif ;
- polish graphique lourd.
