- interface de jeu, pas de logiciel SaaS ;
- ambiance chaleureuse, humaine, atelier/garage technologique ;
- bleu nuit + cyan + ambre/or ;
- Nora = vrai guide ;
- progression de l'entreprise visible ;
- même jeu Windows/Android, mise en page responsive ;
- CPU d'abord, mais vision hardware complète : GPU, RAM, cartes mères, stockage, IA, robotique, serveurs/datacenters.
